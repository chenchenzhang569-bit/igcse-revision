Introduction to Probability

  • Probability is the study of chance or the likelihood of an event happening
P(event)=Number of favourable outcomesTotal number of outcomes P(event) = \frac{\text{Number of favourable outcomes}}{\text{Total number of outcomes}} P(event)=Total number of outcomesNumber of favourable outcomes​

  • If probability = 0, the event is impossible

  • If probability =1, the event is certain to happen

  • If probability = 0.5, there is an even chance

  • All probabilities lie between 0 and 1

  • Probability can be written in

    • Fraction

    • Decimal

    • Percentage

  • P(A)=1−P(A′)P(A) = 1 - P(A')P(A)=1−P(A′)

  • Probability of A happening=1−Probability of A Not Happening\text{Probability of A happening} = 1 - \text{Probability of A Not Happening}Probability of A happening=1−Probability of A Not Happening

Independent Events

  • Two events are independent if the occurrence of one is unaffected by occurrence of other

The OR Rule

  • Refers to the probability of either event happening (or both)

  • Rule: P(A or B)=P(A)+P(B)−P(A∩B)P(A \text{ or } B) = P(A) + P(B) - P(A \cap B)P(A or B)=P(A)+P(B)−P(A∩B)

  • If events are mutually exclusive:

    • P(A or B)=P(A)+P(B)P(A \text{ or } B) = P(A) + P(B)P(A or B)=P(A)+P(B)

The AND Rule

  • Refers to the probability of two events happening together.
  • Rule: P(A and B)=P(A∩B)P(A \text{ and } B) = P(A \cap B)P(A and B)=P(A∩B)
  • If events are independent:
    • P(A∩B)=P(A)×P(B)P(A \cap B) = P(A) \times P(B)P(A∩B)=P(A)×P(B)

  • Calculate using tree diagrams:

  • First branches = 1st event outcomes

  • Second branches = 2nd event outcomes

  • Write probabilities next to each branch

  • Multiply along branches for combined probabilities

  • Add if multiple paths lead to the desired outcome

  • Note: The probabilities reduce with each step if objects are not replaced

Calculate using two-way tables:

  • Column and row headers are the sample space of the two events

    • Take the required number from the table and divide by the sum of all values in the row/column of the condition provided.

Relative & Expected Frequencies

Expected Frequencies

  • This is the number of times we would expect an event to occur over a given number of trials that take place during an experiment

    Expected Frequency=Probability of Event×Number of Trials\text{Expected Frequency} = \text{Probability of Event} \times \text{Number of Trials}Expected Frequency=Probability of Event×Number of Trials

Relative Frequencies

  • Relative frequency is an estimate of the probability of an event based on experimental (or observed) results rather than theoretical probability.

  • Relative Frequency=Number of times event occurstotal number of trials\text{Relative Frequency} = \frac{ \text{Number of times event occurs} }{ \text{total number of trials} }Relative Frequency=total number of trialsNumber of times event occurs​

  • Example

    If you toss a coin 100 times and it lands on heads 55 times, the relative frequency of getting heads is: 55100=0.55\frac{55}{100} = 0.5510055​=0.55
